---
title: "A count for the cube"
---

An ongoing research project aiming to provide an upper bound for number of possible shapes that can be made with the [Shashibo cube]("https://funinmotiontoys.com/products/shashibo?srsltid=AfmBOorZ--8UOWdK5GcKaSo0EVdhOfW3DawNgZzOOk-AUBmIcfnk2NOB"). The Shashibo cube ("shape shifting box") is a toy made up of twelve triangular magnets, boasting the ability to make "70+ shapes." Using tools from group theory and combinatorics, the goal of this project is to provide as small of an upper bound as possible on the number of shapes that can be made.
