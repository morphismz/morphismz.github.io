The Eckmann-Hilton argument

I contributed the “homotopical version” of the Eckmann-Hilton argument to agda-unimath. This version of the argument allows one to compute the transport along an Eckmann-Hilton identification. See the Eckmann-Hilton page for both the argument and the computation of transport.
